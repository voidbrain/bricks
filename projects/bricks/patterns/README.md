# @voidbrain/bricks/patterns

Compositions of bricks components: status row, approval card, data table, filters, empty state. None has landed yet; each is added on real demand ([F-003](../../../docs/BACKLOG.md#f-003), steps T05 and T06) with its spec, catalogue entry and style-guide line, and named in `PATTERNS`.

Angular 22's `@angular/build:library` builds an entry point from `projects/bricks/package.json` `exports` (`"./patterns": "./patterns/public-api.ts"`); there is no `ng-package.json`.
